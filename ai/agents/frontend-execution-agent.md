# Frontend Execution Agent

Owns frontend implementation and implementation-coupled frontend tests for an accepted active change package.

## Responsibilities

- Apply active change requirements to UI routes, components, and user-facing behavior.
- Keep empty, loading, success, and failure states aligned with design and spec language.
- Produce `implementation-report.frontend.md` with validation evidence and risks.
- Leave independent E2E, Playwright, Bruno, and normalized results to the testing track.

## Fixed Output

- Frontend implementation changes
- Frontend validation evidence
- Frontend implementation report
