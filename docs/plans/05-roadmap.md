# 城市 AI 骑行计划 Agent 路线图

版本：v0.1  
更新时间：2026-05-31  
状态：草稿

## 1. 路线图原则

- 先验证单次骑行决策闭环
- 先把杭州做深，再做城市复制
- 先保证推荐可信，再追求推荐聪明

## 2. Phase 1：MVP01 出发前骑行决策

目标：

- 围绕个人出发前决策跑通双场景闭环
- 支持“今晚 / 下午市区内即时骑行”和“周末 / 节假日 2 到 3 天游骑行出行”
- 先给建议去 / 谨慎 / 不建议，再给路线或周末出行方案
- 杭州作为默认样板城市，周边方向优先覆盖千岛湖、湖州等可过夜目的地

范围：

- 自然语言输入
- 定位优先，手动出发点兜底
- 关键约束追问
- 市区即时骑行路线生成
- 周末 2 到 3 天游出行计划
- 基础风险评估
- 装备建议、住宿建议和天气窗口
- 决策结论 + 主推荐 + 备选 + 路书输出

## 3. Phase 2：周边半日游 / 一日游增强

> 口径说明：新的 MVP01 已经吸收周末 / 节假日 2 到 3 天游骑行出行。这里的 Phase 2 后续应重新定义为数据质量、更多目的地和分享 / 收藏增强，而不是最早版本里的“首次周边游能力”。

目标：

- 从“骑一条路线”升级到“安排半天 / 一天”
- 验证用户是否愿意把工具用于周末和节假日周边出行计划

增强内容：

- 周边游模式入口
- 目的地偏好和停留节奏
- 节奏建议
- 骑后休闲点推荐
- 返程和撤退方案
- 节假日拥挤风险
- 更丰富的半日 / 一日场景模板

Phase 2 MVP 仍以杭州为样板城市，具体范围见 `docs/product/03-prd-phase2-nearby-trips.md`。多城市复制在 Phase 4 才作为主目标。

## 4. Phase 3：小程序化

目标：

- 进入更自然的使用场景

增强内容：

- 微信登录
- 常用偏好保存
- 分享结果卡片
- 小程序内结果页适配

## 5. Phase 4：多城市扩展

目标：

- 验证“通用框架 + 城市策略层”的可复制性

候选城市方向：

- 上海：平路长距离与城市滨江
- 成都：周边爬坡和城郊路线
- 深圳：滨海和爬坡混合场景

## 6. Phase 5：数据闭环与推荐增强

目标：

- 从规则可用走向推荐更准

增强内容：

- 用户采纳反馈
- 用户偏好学习
- 推荐结果质量评估
- 风险模型优化
