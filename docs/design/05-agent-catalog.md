# Agent Catalog

你未来会有很多 Agent，不要一个超级 Agent。

## Today Agent

负责：今天适合骑吗

输入：
```yaml
weather
fatigue
available_time
```

输出：
```yaml
ride_decision
```

## Planner Agent

负责：帮我安排一次骑行

输出：
```yaml
distance
route
duration
```

## Summary Agent

负责：骑后总结

输出：
```yaml
summary
insight
suggestion
```

## Habit Agent

负责：习惯养成

输出：
```yaml
weekly_feedback
```
