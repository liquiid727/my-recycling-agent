# Over Cycling - 产品愿景

> 为那些喜欢骑车，但没打算成为骑行大神的人设计。

## 产品定位

Over Cycling 不是专业训练平台。

- 不是 Garmin
- 不是 Strava
- 不是 TrainerRoad

而是一个帮助普通人真正骑出去的骑行陪伴 Agent。

### 解决的问题

```text
想骑车
↓
不知道什么时候骑
↓
不知道去哪骑
↓
不知道骑多少
↓
懒得规划
↓
最后没骑
```

### 使命

```text
从想骑
↓
到真的骑出去
```

## 产品设计理念

Over Cycling 为程序员、设计师、产品经理和城市上班族而做。它不谈竞速，不卷数据，只帮你在周末更轻松地出门、晒太阳、穿过树荫和街角，重新感受城市。

- **0 压力**：没有排行榜，没有训练指标，只有一个更愿意出门的周末。
- **30 分钟**：下班后也能完成的轻骑行建议，不需要为了运动重新安排人生。
- **5 种心情**：散心、晒太阳、喝咖啡、逛公园、看看新街区，路线从情绪出发。
- **1 座城市**：你熟悉的地方，也可以重新变得有趣一点、慢一点、轻一点。

不是训练工具，也不是骑圈社交产品。Over Cycling 只服务一种真实生活：忙了一周的人，想在周末轻松出门，骑一段舒服的路。

天气正好，要不要出去绕一圈，看看太阳、树影和今天这座城市的样子。

Over Cycling 帮偶尔骑车的人找到轻松路线、咖啡停靠点和适合今天的出门理由。像朋友一样邀请你晒晒太阳。

像翻城市旅行杂志一样找路线。

它会记得你喜欢树荫、咖啡和不太拥挤的路，也会在你累的时候把计划变短。

## 用户生命周期

### 骑前

用户问题：
```text
今天适合骑吗？
周末去哪骑？
帮我安排一下。
```

Agent 职责：
- 天气分析
- 时间评估
- 骑行建议
- 路线推荐

### 骑中

用户问题：
```text
前面有暴雨怎么办？
我有点累了。
```

Agent 职责：
- 实时建议
- 补给提醒
- 安全提醒

### 骑后

用户问题：
```text
今天骑得怎么样？
```

Agent 职责：
- 骑行总结
- 成就反馈
- 习惯记录

### 恢复阶段

用户问题：
```text
明天还要骑吗？
```

Agent 职责：
- 恢复建议
- 下次骑行规划

## 不做什么

V1 不做：
- FTP分析
- 功率训练
- 比赛备赛
- 专业教练系统
- 骑行社交社区
- 骑行商城

保持简单。

聚焦：
```text
帮助用户骑出去
```

## 产品哲学

很多骑行软件都在帮助用户骑得更快。

Over Cycling 希望帮助用户骑得更久。

不是成为职业骑手。

而是在工作和生活之间，保留一份属于自己的骑行时间。

## North Star

```text
每周至少骑一次
```

如果用户持续一年做到这一点，Over Cycling 就成功了。
